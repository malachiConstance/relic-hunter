Step 2: Modify QuestGenerator.ts
Add this near the top of generateQuests() or in a new getActiveQuests() function:
TypeScriptimport { TUTORIAL_QUESTS } from '../data/tutorialQuests';

export function getCurrentQuests(state: GameState) {
  const { tutorialStep, collected } = state;

  if (tutorialStep < 5) {
    const currentTutorial = TUTORIAL_QUESTS.find(q => q.step === tutorialStep + 1);
    if (currentTutorial) {
      // auto-update progress based on current collection
      const updated = updateTutorialProgress(currentTutorial, collected);
      return [updated];                    // only show the current tutorial quest
    }
  }

  // After tutorial → normal dynamic quests
  return generateDynamicQuests(state);
}
Step 3: Progress updater (add this helper)
TypeScriptfunction updateTutorialProgress(quest: any, collected: string[]) {
  let newProgress = 0;

  if (quest.targetRelicIds) {
    newProgress = quest.targetRelicIds.filter(id => collected.includes(id)).length;
  } else if (quest.targetCategory) {
    newProgress = collected.filter(id => 
      relics.find(r => r.id === id)?.category === quest.targetCategory
    ).length;
  } else if (quest.requiredCollectionCount) {
    newProgress = Math.min(collected.length, quest.requiredCollectionCount);
  }

  return { ...quest, progress: newProgress, isCompleted: newProgress >= quest.maxProgress };
}

6. How the Player Experiences It (Concrete Flow)

First launch → Tutorial Quest 1 appears on Quest Board with big glowing border.
Only the Santo Chiodo ring is highlighted on the map. Everything else is dim.
Tap → see teaser only → Begin Procession → short walk → spectacular arrival ceremony (you already have the animation code).
After collecting the Nail → Tutorial Quest 2 unlocks automatically.
Now the player knows they must walk to Sant’Ambrogio for a BONE relic.
Quest 3 teaches the three-axis system by requiring Primaria + Secundaria.
Quest 4 uses today’s real Good Friday feast as the example.
Quest 5 forces the player into the Chapel so they understand where relics actually live.

By the end of these 5 quests the player has:

Walked 4–6 processions
Seen teasers vs full reveals
Understood categories, dignity, feasts, and the Chapel
Earned their first Latin titles
Felt the TA-DAAAA moment multiple times

After step 5 the normal dynamic Quest Board (your existing 3 quests) takes over, and Rome silhouettes start to “whisper”.
