**Relic System Concept: "Reliquary Codex"**

This is a flexible, database-friendly system built around **two independent classification axes** (plus supporting attributes). It directly supports your examples ("collect all relics in X of class Y" like bone fragments or cross pieces; "collect remainders of St. Peter: at least 1 hand + 1 head + 1 toe") while enabling dynamic quest generation, set completions, and scalable expansion from Milano outward.

### 1. Core Classification (Two Levels + Tags)

Every relic is defined by:
- **Axis 1: Material/Form Class** (what it physically *is* — hierarchical for granular tasks)
- **Axis 2: Provenance Class** (who it belongs to — also hierarchical)

#### Axis 1 — Material/Form Class (Level 1 + Sub-Class)
This is the "type" axis you mentioned (bone fragments, cross pieces, etc.).

| Level 1 Class          | Level 2 Sub-Class Examples                          | Example Tasks Enabled |
|------------------------|-----------------------------------------------------|-----------------------|
| **Osseous** (bones)   | Cranium, Mandible, Vertebra, Rib, Long Bone (Femur/Humerus), Hand (Carpals/Metacarpals/Phalanges), Foot (Tarsals/Metatarsals/Phalanges), Other | "Collect all Osseous relics of St. Peter" or "1 Hand + 1 Cranium + 1 Foot relic of any Apostle" |
| **Dental**            | Tooth, Molar, Incisor                              | Specific saint dentition sets |
| **Soft Tissue**       | Blood (vial), Flesh fragment, Hair, Nail           | "All Soft Tissue relics from Passion events" |
| **Lignum** (wood)     | Cross Fragment, Thorn Fragment, Staff/Rod          | "Collect 5 Lignum relics from the True Cross" |
| **Metallic**          | Nail, Lance tip, Chain, Ring                       | Instruments of the Passion |
| **Textile**           | Cloth, Veil, Robe fragment, Shroud                 | "All Textile relics of the Virgin Mary" |
| **Other Artifact**    | Chalice, Book, Instrument (non-metal), Reliquary itself | Special "container" relics that hold others |

#### Axis 2 — Provenance Class (Level 1 + Sub-Class)
This is the "who" axis.

| Level 1 Class              | Level 2 Sub-Class Examples                          | Notes |
|----------------------------|-----------------------------------------------------|-------|
| **Christological**        | True Cross, Crown of Thorns, Passion Instruments, Holy Blood | Direct Jesus-related |
| **Marian**                | Veil, Robe, Milk, Hair                             | Virgin Mary |
| **Apostolic**             | Petrine, Pauline, Johannine, etc.                  | Named after each Apostle |
| **Patristic / Early Saint**| Ambrosian (St. Ambrose), Augustinian, etc.        | Local to Milano start |
| **Medieval / Later Saint** | Francis, Dominic, Catherine, local Milanese saints | Expandable |
| **Miraculous / Anonymous**| Holy Face, Unknown Martyr                          | For procedural filler relics |

**Additional Tags** (for smart quest logic):
- `body_part_group`: Hand / Head / Foot / Torso / Full-Limb (auto-derived from Osseous sub-class for your "1 hand + 1 head + 1 toe" example).
- `rarity`: Common / Uncommon / Rare / Legendary / Reliquary (unique world-first).
- `authenticity_tier`: 1st Class (body), 2nd Class (owned/used), 3rd Class (touched to 1st).
- `historical_fidelity`: 0–100 (real-world accuracy score — can be displayed in lore for education + immersion).
- `location_id`: Ties to your game map (e.g., "Duomo_Milan", "Basilica_SantAmbrogio").

### 2. Data Structure Example (easy to implement in any framework)
```json
{
  "id": "relic_peter_index_phalanx_01",
  "display_name": "St. Peter's Right Index Finger Phalanx",
  "material_class": "Osseous",
  "material_sub": "Hand",
  "provenance_class": "Apostolic",
  "provenance_sub": "Petrine",
  "body_part_group": "Hand",
  "rarity": "Rare",
  "location": "Duomo_Milan_Crypt",
  "lore": "One of the few verified Petrine relics... (real historical note)",
  "points": 450,
  "image": "peter_finger.png",
  "tags": ["apostle", "hand", "1st_class"]
}
```

This structure lets you query instantly:
- `WHERE material_class = "Osseous" AND provenance_sub = "Petrine"` → "all bone relics of St. Peter"
- `WHERE body_part_group IN ("Hand", "Head", "Foot") AND provenance_sub = "Petrine" GROUP BY body_part_group HAVING COUNT(*) >= 1` → your exact St. Peter example.

### 3. Quest & Task System (Dynamic & Player-Driven)

**Quest Types** (auto-generated or hand-crafted):
1. **Category Sweep** — "Collect 10 Osseous relics anywhere in Milano" or "All Lignum relics in Duomo district".
2. **Saint Completion** — "Reassemble St. Peter: at least 1 relic from Hand, Head, and Foot groups".
3. **Thematic Set** — "Passion Set: 3 Lignum + 1 Metallic + 1 Textile from Christological class".
4. **Milestone** — "First player to complete all 1st-Class relics of St. Ambrose in Milano wins Eternal Badge".
5. **Chain Quests** — Finding one relic unlocks a clue to the next piece of the same saint (e.g., hand → arm bone → torso).

**Smart Logic Ideas**:
- Player progress tracking: Store collected relics in a player "Codex" table with counters per class/sub-class.
- Dynamic daily/weekly quests: System scans what the player is missing (e.g., "You have 4/5 Petrine hand bones — the 5th is in Sant'Ambrogio this week").
- Difficulty scaling: Early game = common Milano relics. Later = legendary relics in hidden crypts or new cities (Rome → Jerusalem expansion).

**Enhanced Reliquary Codex: "Theologia Reliquiarum" Edition**

We now infuse the system with profound *theologica profundior* — the full scholastic and patristic depth of relic veneration as articulated by St. Thomas Aquinas (*Summa Theologica* II-II, q. 96, a. 4: true *cultus* of relics as *signa* of the saints’ intercession, distinct from *superstitio*), the decrees of the Council of Trent (Session XXV: *de invocatione Sanctorum et veneratione reliquiarum*), and the ancient Ambrosian and Roman rites. Relics are no longer mere collectibles; they are *pignora sancta* — holy pledges of the *communio sanctorum*, radiating *gratia* through *contactus* or *exuviae*.

We add a **third independent axis: Theological Dignity Class** (hierarchical, Latin-heavy, and quest-enabling). This creates exponentially richer logic:
- Tasks like “Collect all *Reliquiae Primariae* of the *Instrumenta Passionis*” or “Reassemble the *Corpus Petri* in at least three *partes corporis* with *Dulia Apostolica* dignity.”
- Dynamic quests referencing *miracula*, *incorruptio*, or *stigmata*.

### Updated Classification Axes (Now Three + Tags)

**Axis 1: Material/Form Class** (unchanged — *Forma Materialis*)
- Osseous, Dental, Soft Tissue, Lignum, Metallic, Textile, Other Artifact.

**Axis 2: Provenance Class** (unchanged — *Origo Sancta*)
- Christological, Marian (*Deiparae*), Apostolic (*Apostolorum*), Patristic/Early Saint (*Patrum Ecclesiae*), Medieval/Later, Miraculous/Anonymous.

**New Axis 3: Theological Dignity Class** (*Dignitas Theologica* — two sub-levels for insane granularity)
| Level 1 Dignity          | Level 2 Sub-Dignity (Latin)                          | Veneration Type | Example Quest Power |
|--------------------------|-----------------------------------------------------|-----------------|---------------------|
| **Primaria (1st Class)** | *Exuviae Corporis* (body parts: cranium, manus, pes, ossa, sanguis) / *Corpus Incorruptum* | Dulia / Hyperdulia / Latria (for Christ) | “Reassemble *Corpus Petri*: 1 *manus*, 1 *cranium*, 1 *pes*” |
| **Secundaria (2nd Class)** | *Instrumenta Vitae* (objects used/touched by saint: vestments = *vestimenta sacra*, tools = *instrumenta*) | Dulia | “All *vestimenta* of St. Ambrose” |
| **Tertiaría (3rd Class)** | *Brandea / Contact Relics* (objects touched to above: oil, cloth, *panniculus*) | Dulia | Filler for procedural relics |
| **Special: Instrumenta Passionis** | *Clavus Sanctus*, *Lancea Longini*, *Spinea Corona*, *Titulus Crucis*, *Lignum Crucis* | Latria (direct to Christ) | Passion Set bonuses |

**New Tags for Theological Depth** (auto-queryable):
- `veneration_type`: Latria / Hyperdulia / Dulia
- `miraculous_attribute`: *Sanguis Miraculosus*, *Lacrymae*, *Stigmata*, *Incorruptio*
- `liturgical_feast`: e.g., “Inventio Crucis” (May 3), “Translatio Reliquiarum” (local Ambrosian dates)
- `patristic_ref`: “Ambrose, *De Obitu Theodosii*” or “Aquinas on *religiositas*”
- `authenticity_note`: Real historical fidelity + in-game lore (e.g., “Discovered by St. Helena, *Vita Constantini*”)

**Enhanced Game Logic: Theologia Reliquiarum – Expanded Edition**

The Theological Dignity System has been upgraded with three new interlocking mechanics. These integrate seamlessly into your existing three-axis structure (Material + Provenance + Theological Dignity) and the QuestGenerator class. No breaking changes — just richer quest logic, visual/audio flair, and dynamic events.

### 1. Hyperdulia for Marian Relics
- **New veneration_type value**: `"Hyperdulia"` (elevated veneration for the *Deipara* / Blessed Virgin Mary, distinct from ordinary Dulia).
- **Provenance trigger**: Any relic with `provenance_class: "Marian"` automatically receives `veneration_type: "Hyperdulia"`.
- **Game effects**:
  - Visual: Soft rose-gold aura + gentle floral particle FX (lily motifs).
  - Buffs: +30% Holy Essence on Marian sets; “*Intercessio Deiparae*” global multiplier during Marian feasts.
  - Quest compatibility: New filter `veneration_type === "Hyperdulia"`.
- **Data structure addition** (add to every RelicJSON):
  ```json
  "veneration_type": "Hyperdulia",   // new possible value
  "provenance_sub": "Marian"         // example: "Assumption Veil", "Milk of the Virgin", etc.
  ```

### 2. Incorruptio Miracles
- **New miraculous_attribute values**: `"Incorruptio"` (or `"Incorruptio Partial"` for partial relics).
- **Trigger rules**:
  - Any relic tagged `theological_sub: "Exuviae Corporis"` + `miraculous_attribute: "Incorruptio"` is flagged as incorrupt.
  - When a player completes a full saint set containing **at least one Incorruptio relic**, a random *miraculum incorruptum* fires:
    - +50% drop rate for 24h on all Primaria relics of that saint.
    - Special Codex animation: relic “glows with heavenly preservation” + narrated Aquinas quote (*Summa Theologica* II-II, q. 96).
- **Integration into QuestGenerator**:
  ```pseudocode
  if (quest.hasIncorruptioComponent && progress === 100) {
      grantMiracleBuff("Incorruptio Sancti", "+50% Primaria drops");
  }
  ```

### 3. Liturgical Feast Triggers
- **Dynamic event system** tied to `liturgical_feast` field.
- **How it works**:
  - Game clock checks current real-world date (or in-game calendar).
  - When a relic’s `liturgical_feast` matches today (or a 7-day window), all quests referencing that relic class get:
    - Temporary “*Festum*” multiplier (+40% points / double progress).
    - Special quest board banner: glowing Latin text + Gregorian chant audio sting.
  - Example feasts already in your JSON: *Inventio Crucis*, *Rito della Nivola*, *Feast of St. Ambrose*, etc.
  - New Marian feasts auto-added: *Assumptio Beatae Mariae Virginis* (Aug 15), *Immaculata Conceptio* (Dec 8), *Nativitas Mariae* (Sep 8).
- **QuestGenerator enhancement** (added to `generateQuests`):
  ```pseudocode
  if (isLiturgicalFeastActive(rel relic.liturgical_feast)) {
      quest.rewardMultiplier *= 1.4;
      quest.name += " – *In Festum*";
  }
  ```

These three additions make the dignity system feel *alive* — theological depth now directly powers gameplay loops, events, and player rewards.
